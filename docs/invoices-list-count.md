# Contador de facturas visibles

El título de la página Facturas muestra el número de filas de factura presentadas en la tabla con el formato «Facturas (N)». Cuando aparecen FAC-8812 y FAC-8790, el título indica «Facturas (2)» y la tabla presenta esas dos filas.

Si la lista está vacía, el título indica «Facturas (0)» y la tabla no presenta filas de factura.
