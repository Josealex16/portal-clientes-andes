# Orden de la tabla de Pedidos

La tabla de Pedidos muestra primero los pedidos con fecha más reciente y termina con el más antiguo. Con los datos de ejemplo, el orden es `PED-2041`, `PED-2037`, `PED-2029`, `PED-2018`, `PED-2003`; por tanto, `PED-2041` aparece primero y `PED-2003` último.

El cambio afecta solo al orden de las filas. Se conservan las columnas «N°», «Fecha», «Detalle», «Total» y «Estado», el formato de fecha `DD/MM/AAAA` y los valores de ejemplo de cada pedido.
