# Contador de pedidos visibles

El título de la página Pedidos muestra el número de filas de pedido de la tabla con el formato «Pedidos (N)». Por ejemplo, cuando aparecen PED-2041 y PED-2037, el título indica «Pedidos (2)» y PED-2029 no aparece.

Si la lista está vacía, el título indica «Pedidos (0)» y la tabla no presenta filas de pedido. El contador refleja la lista recibida por la página; si esta ya contiene resultados de un filtro o una búsqueda, cuenta solo esas filas y no añade controles de filtrado.
