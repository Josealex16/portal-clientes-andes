# Acceso a Soporte desde la página 404

Cuando se muestra «Página no encontrada» para una dirección inexistente, la página ofrece «Volver al inicio» y, debajo, «Ir a Soporte». Este segundo enlace lleva a `/soporte`.

Por ejemplo, al abrir `/pagina-inexistente`, se muestra «Página no encontrada» con los enlaces «Volver al inicio» y «Ir a Soporte» en ese orden; el destino de este último es `/soporte`.
